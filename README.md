# 🎮 Mitt första Python-projekt

Det här är ett litet Python-projekt som jag har gjort i kursen **Programmering 1** på Teknikprogrammet.

Projektet är ett enkelt gissningsspel där datorn väljer ett slumpmässigt tal och spelaren ska försöka gissa vilket tal det är.

## 📋 Funktioner

Programmet kan:

- Slumpa fram ett tal mellan 1 och 100
- Ta emot gissningar från användaren
- Tala om ifall gissningen är för hög eller för låg
- Räkna hur många försök spelaren har gjort
- Visa resultatet när spelaren gissat rätt

## 💻 Så här kör du programmet

Du behöver ha Python installerat på datorn.

1. Klona repot eller ladda ner filerna.
2. Öppna projektmappen i Visual Studio Code.
3. Öppna filen `testFile.py`.
4. Kör programmet.

Du kan till exempel köra programmet från terminalen med:

```bash
python testFile.py
